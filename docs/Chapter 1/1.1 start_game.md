# Chapter 1. 安装游戏

不同于手机游戏或 Steam 平台的一键安装，Minecraft 的安装较为复杂。

目前，主流的Minecraft安装方式主要包括在官网购买正版和使用启动器。如果你是Minecraft的小萌新，建议使用PCL启动器进行安装。在接下来的1.1节中，可以直接点击对应标题跳转到相关内容。

### 1.1.1 各安装方法的解释

> 1. 什么是启动器？

实际上Minecraft的安装分为**下载**和**启动**两个环节。无论是在官网上下载的还是在第三方启动器中下载的，都是游戏本体。然而这个游戏本体并不是一个可以双击执行的程序，需要通过官方提供的**官方启动器**或者第三方启动器（如PCL， HMCL）启动。


它看起来只是个“快捷方式”，但其实远不止如此。Minecraft 历经十余年多个版本的更新迭代，以及模组和资源包的丰富发展，游戏本体和附加内容变得越来越复杂。你可以发现，你前前后后下载了各种原版、模组整合包的 Minecraft，每次启动肯定需要什么东西管理。

启动器可以方便地**安装**和**切换不同版本**的 Minecraft，以及管理模组和资源包。

> 2. 什么？这游戏我不买正版就能玩吗？

事实上，确实可以。

Minecraft在官网购买的正版，本质上是一个由Minecraft官方提供的正版账号，可以通过正版身份验证。正版 Minecraft 提供了**官方**的完整游戏体验，包括使用正版的多人游戏和大型服务器（例如 Hypixel）、Realms（领域服务器）等。正版用户可以个性化自己的游戏形象，可以前往 [Minecraft 官网](https://minecraft.net/)，上传个性皮肤、更改游戏 ID 等。

一些启动器提供的**离线登录**功能，允许玩家在不进行正版验证的情况下启动游戏，但是无法使用个性化皮肤和正版服务器。因此你会在某些服务器看到大量[默认皮肤](https://zh.minecraft.wiki/w/%E7%9A%AE%E8%82%A4#%E9%BB%98%E8%AE%A4%E7%9A%AE%E8%82%A4)的玩家。

简单来说就是，不买正版也能通过第三方启动器玩，可以正常联机、加载mod，但无法加入某些需要正版验证的服务器。

当然了，还是建议支持正版游戏。无论是出于更好的游戏体验，还是对这款游戏的热爱。


> 3. 为什么推荐用PCL？

因为PCL可以全自动帮你配置Java环境。

Java版的MC当然是基于Java运行的（这不是废话么），所以启动MC的必要条件是你的电脑上需要下载Java。

但是考虑到Java的下载、版本选择等等比较复杂，所以这里还是推荐直接使用PCL。PCL在你点击运行游戏时就会帮你自动选择并下载合适的Java，全程不用你动手。
